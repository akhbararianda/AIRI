# AIRI Wallpaper

AIRI Wallpaper v1.0 is a native Android wallpaper app designed to be lightweight, offline-first, and easy to monetize later.

Current build includes:
- modern dark gallery UI
- generated premium-style wallpaper collection (no copyrighted image assets bundled)
- categories and featured collection
- fullscreen preview
- set wallpaper for home screen, lock screen, or both
- favorite toggle stored locally
- offline operation
- Android 7.0+ support

The project intentionally ships without ad IDs, payment credentials, analytics keys, or private secrets. AdMob / Play Billing can be wired after the first stable APK is validated.
